# 安全、驗收與問題回報

## 先確認能自行恢復

保留可操作的 Mac 內建螢幕，首次不要在工作不可中斷時測試。確認可以用三星實體控制選回 USB-C，並能在 macOS 顯示器設定手動還原更新率。

helper 不操作 HDR、USB、全機顯示器電源或 WindowServer。CoreDisplay 私有符號僅用於唯讀身分，CoreGraphics 用於模式交易；符號不在或配置不符時停止。App 保留的 DDC 診斷使用私有 IOAV 能力，與成功路徑無關；不要當成官方 API。

## 還原不是無條件保證

獨立監護程序在主程序關閉控制 pipe／退出後，僅在完整配置仍等於本次擁有的 temporary 120 Hz 配置時還原一次。已是原配置就不寫入；使用者改動、拔線、鏡像、身分／配置漂移則拒絕覆寫。失敗不追加未授權備援；App 停用返回。

活著但卡住的同步系統交易不能安全強制中斷；監護不與卡住的主程序競爭寫入。工具不保證任何故障下都自動還原。若異常，從內建螢幕查看顯示器設定，不盲目連續重跑。

模式、尺寸、更新率還原不等於已證明 HDR、色彩格式、ICC、音訊路由或所有低階屬性完全不變。請現場確認。

## 一次完整驗收

1. preflight 成功，不存在多外接／鏡像／未知目標。
2. 明確授權的單次手動模式往返，原配置確認成功。
3. 三星實際返回 Mac（不要用 active=true 或 DDC 讀值代替）。
4. 自動返回啟用後，App 收到 PS5 Online，再收到明確 Standby。
5. 只執行一次、監護還原與唯讀確認成功；重複 Standby 不再切。
6. 現場確認畫面、體感、HDR 偏好、桌面配置及音訊沒有不希望的變化。

純單元測試、編譯成功或 API success 不等於第 3／6 項通過。

## 問題回報

先停用自動返回，只記錄重現問題所需的產品型號／韌體主版本、接線、Auto Source Switch+ 狀態、可用 240／120 Hz 模式及實際症狀；不要附完整電腦硬體或系統環境檔案。

App Diagnostics 及 helper 輸出可能含螢幕 UUID、裝置／本機資訊、輸入 IP 及時間。公開 issue 前手動移除 IP、MAC、SSID、UUID、序號、使用者路徑及其他個人資訊；不要附完整系統紀錄、登入憑證或未遮蔽截圖。

建議只貼去識別化的事件：Online／transport failure／Standby、trigger true/false、CGError、guardian exit、modeRestored，以及「現場有／沒有返回」與黑畫面次數。
